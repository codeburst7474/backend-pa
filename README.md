# Frontend Web Projects

Welcome to the Frontend Web Projects repository! This repository contains a collection of modern, interactive frontend web applications built using Vanilla HTML, CSS, and JavaScript.

## 🚀 Features

This repository includes the following projects:

1. **PixelForge - Modern Image Editor** (`/js/game/`)
   - Interactive image editing tool
   - Support for filters (Brightness, Contrast, Saturation, etc.)
   - Transformations (Rotate, Flip, Zoom)
   - Drawing tools (Brush, Eraser)
   - Add custom text and shapes
   - Export images in various formats (PNG, JPG, WEBP)

2. **Modern Kanban Board** (`/js/kandam baord/`)
   - Task management with Drag and Drop functionality
   - Categorize tasks into "To Do", "In Progress", and "Done"
   - Clean, modern UI using the Inter font family

## 💻 Tech Stack

- **HTML5**: Semantic and accessible markup
- **CSS3**: Modern styling, Flexbox, Grid, custom variables, and responsive design
- **JavaScript (ES6+)**: DOM manipulation, event handling, and core application logic
- **Icons & Fonts**: Boxicons and Google Fonts (Inter)

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <your-github-repo-url>
   ```
2. **Navigate to the project directory:**
   ```bash
   cd frotend
   ```
3. **No dependencies required!** Since these are vanilla web projects, you don't need to run `npm install`.

## 🎮 Usage Instructions

To run any of the projects locally:

1. Navigate to the specific project folder (e.g., `js/game/` or `js/kandam baord/`).
2. Open the `index.html` file directly in your web browser.
3. Alternatively, for a better development experience, you can use a local server like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code to avoid any CORS issues and enable hot reloading.
